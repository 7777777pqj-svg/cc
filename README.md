# AI 四棒接力

一个动画页面，演示我的 AI 工作流：

1. **Claude** 规划任务：把想法拆成可交付、可验收的步骤，并分配给后面几棒
2. **Gemini** 搜索调研：查资料、比对来源，交回结论和出处
3. **Codex** 编写执行：按计划写代码、跑测试，失败了自己修
4. **OpenRouter** 扩展链接：一个接口连接多个模型，按任务路由
5. 结果交回 Claude 复盘，开始下一轮
6. 幕后：每月成本，展示三份订阅的 App Store 订单（订单号已打码）

订单截图放在 `assets/receipts/`，没有提交进仓库。缺少截图时，第 6 幕会显示一行提示代替图片。

直接用浏览器打开 `index.html` 即可播放。支持暂停、上一棒/下一棒、点击站点跳转，键盘 ← → 切换、空格暂停；深色模式和手机屏幕都能正常显示。
