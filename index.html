我的 AI 工作流

一个想法，四棒接力

Claude 规划任务，Gemini 搜索调研，Codex 动手执行，OpenRouter 扩展链接。下面用一个真实的小项目，把每一棒演示一遍。

第 1 棒 · Claude · 规划任务

先想清楚，再动手

把一句模糊的想法拆成能交付、能验收的步骤，并决定每一步交给谁。

我说做一个每天早上自动汇总 AI 新闻的小助手。
  1. 定目标：每天 8:00 推送 10 条要点，每条附原文链接Claude
  2. 调研：有哪些靠谱、免费的新闻源和接口→ Gemini
  3. 实现：抓取、去重、摘要、定时推送，测试要全过→ Codex
  4. 接入：模型调用统一走一个入口，按任务挑模型→ OpenRouter
交棒给 Gemini写好 PLAN.md，第一个问题：新闻从哪儿来？
第 2 棒 · Gemini · 搜索调研

广撒网，再收口

带着问题去搜，交叉比对多个来源，把结论和出处一起交回来。

第 3 棒 · Codex · 编写执行

照着规格写，跑通为止

读计划和调研结论，写代码、跑测试；失败了自己定位、修好、再跑。

~/ai-digest
$ codex "按 PLAN.md 和 research.md 实现每日新闻汇总"

交棒给 OpenRoutersummarize.py 里所有模型调用，统一走它的接口。
第 4 棒 · OpenRouter · 扩展链接

一个接口，连上更多模型

同一个 API Key，按任务路由到不同模型。有新模型上线，改一行配置就能接进来。

每日摘要 → 便宜又快的模型疑难分析 → 强推理模型某家故障 → 自动切到备用
交回 Claude上线跑一周，把结果拿回来复盘。

Claude 对照第一步定下的验收标准检查结果，发现缺口就写进新计划，接力再跑一圈。
